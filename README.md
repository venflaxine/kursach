# Локальный антиплагиат — анализатор сходства текстов на N-граммах

Учебный проект на **C++17 и Qt 6 Widgets**. Программа сравнивает два текста локально, строит N-граммы, рассчитывает коэффициент Жаккара и косинусное сходство, показывает общие N-граммы и позволяет сохранить отчёт в UTF-8 TXT.

> Процент сходства — статистическая оценка. Он не доказывает плагиат сам по себе и требует интерпретации человеком.

## Возможности

- Ввод двух текстов вручную или загрузка файлов `.txt` / `.md` в UTF-8.
- N-граммы по словам или по символам.
- Размер N от 1 до 10.
- Настройки обработки: игнорировать регистр и/или пунктуацию.
- Две метрики: Жаккар для множеств уникальных N-грамм и косинусное сходство для векторов частот.
- Статистика: количество N-грамм-вхождений, уникальных N-грамм и общих уникальных N-грамм.
- Таблица общих N-грамм и частоты в каждом документе.
- Экспорт отчёта в TXT.
- Проверки пустого текста, слишком короткого текста, неверного N, слишком больших текстов/файлов, ошибок файловых операций и невалидного UTF-8.
- Автоматические тесты алгоритма на Qt Test.
- GitHub Actions workflow для автоматической сборки и тестирования.

Максимальный размер каждого входного текста — 256 КиБ в UTF-8. Это ограничение уменьшает вероятность чрезмерного расхода памяти при построении частотного словаря.

## Кратко об алгоритме

1. Текст нормализуется согласно настройкам.
2. В зависимости от режима он разбивается на слова или Unicode-кодовые точки.
3. Из последовательности строятся перекрывающиеся N-граммы.
4. Для каждого документа подсчитывается частота каждой N-граммы.
5. Коэффициент Жаккара рассчитывается по множествам уникальных N-грамм:

   `J(A, B) = |A ∩ B| / |A ∪ B|`

6. Косинусное сходство рассчитывается по векторам частот:

   `cos(A, B) = (A · B) / (||A|| × ||B||)`

Более подробное математическое описание, ограничения и псевдокод доступны в [`docs/ALGORITHM.md`](docs/ALGORITHM.md).
