# Алгоритм работы программы

## 1. Входные данные и валидация

На вход алгоритм получает два текста и параметры: размер N, режим построения N-грамм, метрику, чувствительность к регистру и правила очистки текста. До вычислений проверяются непустые тексты, максимальная длина и диапазон N от 1 до 10.

## 2. Нормализация

Если выбрано игнорирование регистра, строка переводится в Unicode case-folded представление. Это предпочтительнее простой замены ASCII-букв, поскольку исходные тексты могут содержать кириллицу и другие алфавиты.

### Словесный режим

Текст обходится по Unicode-кодовым точкам. Буквы, цифры и комбинируемые диакритические знаки формируют токены; пробелы и пунктуация завершают токен. Таким образом, предложение превращается в упорядоченный список слов.

### Символьный режим

Текст преобразуется в последовательность Unicode-кодовых точек. В соответствии с флажками из последовательности исключаются пробельные символы и/или пунктуация. Внутреннее построение символов не разрезает дополнительные Unicode-символы на половины суррогатных пар UTF-16.

## 3. Построение N-грамм

Для последовательности элементов `x[0], x[1], ..., x[m-1]` и размера N строятся фрагменты:

`(x[0], ..., x[N-1]), (x[1], ..., x[N]), ..., (x[m-N], ..., x[m-1])`.

Количество N-грамм с учётом повторов равно `m - N + 1`. Если после нормализации элементов меньше N хотя бы в одном тексте, программа возвращает понятную ошибку вместо вычисления некорректного процента.

Для каждой N-граммы строится частотный словарь `N-грамма -> количество вхождений`.

## 4. Коэффициент Жаккара

Для множеств уникальных N-грамм A и B:

`J(A, B) = |A ∩ B| / |A ∪ B|`.

В данном проекте `|A ∩ B|` — число уникальных N-грамм, присутствующих в обоих текстах. Частоты повторений на значение Жаккара не влияют.

## 5. Косинусное сходство

Каждый текст представлен вектором частот по общему словарю N-грамм. Сходство вычисляется по формуле:

`cos(A, B) = Σ(Aᵢ × Bᵢ) / (sqrt(ΣAᵢ²) × sqrt(ΣBᵢ²))`.

В отличие от Жаккара, косинусное сходство учитывает частоту появления каждой N-граммы. Результат ограничивается диапазоном [0; 1] для защиты от малых ошибок вычислений с плавающей точкой.

## 6. Вывод результата

Интерфейс показывает оценку в процентах, число всех и уникальных N-грамм каждого текста, число общих уникальных N-грамм и до 100 общих N-грамм, упорядоченных сначала по числу общих вхождений. По желанию пользователя сводка сохраняется в UTF-8 `.txt`.

## 7. Сложность

Пусть L — число элементов в последовательности, а U — число уникальных N-грамм. Формирование частотного словаря на основе `QMap` в общем случае занимает `O(L log U)`. Сравнение двух словарей и сортировка списка общих N-грамм занимают до `O(U log U)`. Использование лимита длины текста ограничивает потребление памяти на больших входах.

## 8. Интерпретация

Полученный процент — это мера лексического сходства, а не автоматический вердикт о плагиате. Он не учитывает авторство, источники, смысловую эквивалентность, цитирование или правила конкретного учебного заведения. Окончательная оценка требует контекста и экспертного просмотра совпавших фрагментов.
